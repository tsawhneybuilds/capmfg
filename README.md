# capmfg

Static GitHub Pages site for the manufacturing-capacity thesis walkthrough.

The page reports provisional real-data descriptive tests from India's Annual
Survey of Industries and preserves the boundary between those patterns and the
thesis's unestimated causal hypotheses. Aggregate replication outputs and the
analysis script are in `analysis/`.
